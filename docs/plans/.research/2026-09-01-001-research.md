# Research: Fix end-session Skill Gaps

## Patterns Found

1. **Frontmatter conventions**: plan, work, review, learn all include `disable-model-invocation`, `version`, and `timestamp` in their SKILL.md frontmatter. end-session lacks all three.
2. **interactionMode**: Every orchestrator-level skill asks the user to choose Detailed/Smart/Autopilot before the pipeline starts. end-session has no such mechanism.
3. **Artifact persistence**: Every skill saves phase artifacts. end-session saves nothing.
4. **Error handling**: All skills share a `references/error-handling.md` with Category 1-5+ error tables, retry limits, and recovery workflow. end-session has none.
5. **Learn path**: The canonical path is `docs/learn/index.md`. `docs/learnings/INDEX.md` does not exist.
6. **No /update-learnings**: The Learn skill defines `/learn` and `/learn maintain` only. There is no `/update-learnings` skill.
7. **Tool-agnostic principle**: ARCHITECTURE.md and all core skills prohibit hardcoding specific tool commands.

## Risk Assessment

- **Low-Medium**: Changes are additive or subtractive within a single skill file.
- **Medium**: Removing version-bump detection is a behavioral change.
