**Arreio** (Brazilian word for _harness_) transforms agentic coding workflows into a predictable, safe, and high-quality software delivery pipeline.

By enforcing a **pragmatic**, guardrailed execution, Arreio brings structure to AI-driven development. Master just four core phases to orchestrate a highly reliable development cycle:

**Plan → Work → Review → Learn**

## Skill Based Workflow

**Arreio** orchestrates work through predictable skills that run in sequence:

Use /arreio to orchestrates four micro-skills in sequence:

### Plan

| Phase | Module Name       | Purpose                                   |
| ----- | ----------------- | ----------------------------------------- |
| 1     | **plan-scope**    | Gather context, validate domain           |
| 2     | **plan-research** | Discover patterns, detect high-risk areas |
| 3     | **plan-design**   | Decompose into implementation units       |
| 4     | **plan-generate** | Select tier, render plan, save to docs    |

### Work

| Phase | Module Name      | Purpose                                   |
| ----- | ---------------- | ----------------------------------------- |
| 1     | **work-triage**  | Classify input and extract context        |
| 2     | **work-prepare** | Set up environment, move task to progress |
| 3     | **work-execute** | Implement with test-first discipline      |
| 4     | **work-review**  | Code review, quality gates, move to done  |

### Review

| Phase | Module Name        | Purpose                          |
| ----- | ------------------ | -------------------------------- |
| 1     | **review-scope**   | Classify input and scope review  |
| 2     | **review-prepare** | Set up review environment        |
| 3     | **review-analyze** | Execute code review, find issues |
| 4     | **review-report**  | Report verdict                   |

### Learn

| Phase | Module Name         | Purpose                    |
| ----- | ------------------- | -------------------------- |
| 1     | **learn-extract**   | Extract patterns from work |
| 2     | **learn-classify**  | Categorize learning type   |
| 3     | **learn-dedup**     | Check for duplicates       |
| 4     | **learn-save**      | Save to persistent storage |
| 5     | **learn-structure** | Update learnings INDEX     |
